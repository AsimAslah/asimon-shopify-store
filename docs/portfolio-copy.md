## Portfolio project title

ASIMON Fashion Studio — Premium Shopify Fashion Storefront

## Short project description

Designed and developed a premium Shopify fashion storefront using Liquid, HTML, CSS, JavaScript, Shopify CLI, and GitHub. The project includes a responsive editorial homepage, merchant-editable content, real product collections, variant-ready product pages, native cart behavior, and a safe feature-branch workflow.

## Detailed case-study description

ASIMON Fashion Studio transforms Shopify's Horizon foundation into a focused fashion experience. I created a responsive editorial hero, connected real Shopify collections and products, refined product merchandising, preserved Shopify's native cart and checkout paths, and organized development through tested GitHub pull requests. The storefront is designed so merchants can change core content through the theme editor without editing code.
